# 国内平台反爬模式速查

国内主流内容平台（知乎、百度、B站、微信、小红书等）普遍使用 **反爬机制**，与服务器的物理地域 **无关**。国内云服务器（百度云、阿里云、腾讯云等）直连这些平台时，curl 请求同样会被拦截。

## 各平台 curl 访问结果

| 平台 | curl 行为 | 原因 | 有效替代 |
|------|-----------|------|----------|
| **百度搜索** | HTTP 200，但返回 CAPTCHA 验证页面 | 检测到无浏览器指纹（UA/Cookie/JS）——即使携带 Cookie + CookieJar 持久化会话也无效。百度需要真实的 JS 执行环境 | **360搜索**（推荐，curl 可用）、搜狗（部分可用）、浏览器工具 |
| **360搜索** | ✅ **完全可用**，返回完整结果页 | 反爬较宽松，支持简单 curl 请求。搜狗搜不到时优先试它 | 首选中文搜索引擎替代方案 |
| **知乎** | HTTP 405 Method Not Allowed | IP/UA 级别封禁 curl | 需 `ZHIHU_COOKIE` 或浏览器 |
| **微信文章** | HTTP 200，返回空白 DOM（`document.title = '微信公众平台'`） | 未登录态，DOM 无内容 | 浏览器登录后访问 |
| **Bing 中文版** | 返回结果但查询词被拆成单字（如"刘"→只搜"刘"） | URL 编码被服务端重写 | 360搜索、搜狗、DuckDuckGo |
| **搜狗搜索** | 部分可用，但结果链接多为 `mp.weixin.qq.com` 跳转链接 | 反爬较宽松，但内容来源受限 | 配合手机UA和移动版URL |
| **Semantic Scholar** | 空响应 / 429 Too Many Requests | 公开 API 限速（无 key 约 1 req/sec） | 传 `S2_API_KEY` 或用浏览器 |
| **B站** | 基本可用（无需 cookie 的基础搜索） | 反爬较弱 | sn-search-social-cn 脚本 |
| **小红书** | 需登录 + 设备指纹 | 强反爬 | 仅限浏览器+用户登录 |

## 核心原则

**「搜不到 ≠ 海外无法访问」** — 先判断是反爬拦截还是地域限制：

1. **curl 返回 CAPTCHA/空白/405** → 反爬拦截 → 换浏览器工具或携带 Cookie
2. **curl 返回 403/连接超时/DNS 失败** → 可能是地域/网络限制
3. **浏览器也失败** → 可能是登录墙或平台真封锁

## 推荐的搜索策略

### 第一梯队（curl 直接可用）
- **360搜索** (`so.com`): ✅ **首选**。反爬最宽松，curl 直接返回完整结果页，可提取标题和重定向链接。推荐做中文搜索第一选择。
- **搜狗搜索** (`sogou.com`): 中文内容发现入口，但结果多为微信跳转链接，需二次解析
- **百度快照** (`cache:`): 绕过验证页获取网页快照内容

### 第二梯队（需浏览器工具）
- **Hermes 内置浏览器** (`browser_navigate` + `browser_snapshot`): 携带完整浏览器指纹，可绕过大部分反爬
- **需要登录时**：在浏览器的页面中请求用户手动登录，登录后继续操作

### 第三梯队（特定平台的脚本）
- **sn-search-social-cn**: B站搜索无需 cookie，知乎/抖音需 cookie
- **sn-search-academic**: Semantic Scholar 可传 API key 提升限额；ArXiv/Wikipedia 无需认证

## 常见反爬类型及识别

| 反爬手段 | 识别信号 | 对策 |
|---------|---------|------|
| CAPTCHA | 页面包含"安全验证""请输入验证码"等字样 | 用浏览器工具（带完整指纹） |
| UA 检测 | 返回 405/403 或空内容 | 设 `User-Agent: Mozilla/5.0 ...` |
| Cookie 验证 | 返回空 DOM/跳转登录页 | 携带有效 Cookie 或用浏览器登录 |
| 请求频率限速 | 返回 429/空响应/随机超时 | 增加请求间隔，传 API key |
| JS 渲染要求 | 页面内容不在 HTML 中 | 用浏览器工具渲染 |
| URL 重写 | 搜索词被错误拆分或替换 | 换搜索引擎 |
