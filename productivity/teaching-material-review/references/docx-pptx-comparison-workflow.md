# docx 讲稿与 pptx 逐页比对工作流

## 触发条件
用户提供同名的 `.docx`（讲稿）和 `.pptx` 文件，要求检查讲稿内容与每页 PPT 是否匹配、内容是否准确清晰、言简意赅。

## 工作流

### 1. 文件发现
```bash
ls /目录/           # 找出同名 .docx 和 .pptx 文件对
```

### 2. 读取 docx 讲稿
使用 `read_file` 自动提取 docx 内容。讲稿通常按 `P1, P2, ..., Pn` 标记页码。阅读时先检查编号完整性——P 编号重复或跳跃意味着需要修复。

### 3. 读取 pptx 幻灯片
用独立 python-pptx 脚本提取每页文本（参见 `teaching-material-review` 主技能的 Step 2）。

### 4. 逐页比对
对每个 Pn 编号，检查：
- **核心概念一致**：讲稿不遗漏 PPT 的关键知识点
- **口语化适当**：讲稿可补充口语解释，但不应偏离 PPT 内容
- **页码编号正确**：P4 出现两次 → 编号错乱，必须修正
- **深度匹配**：讲稿不宜超出 PPT 展示范围太多（如讲 CLIP/MM-DiT 但 PPT 只有三步流程图），否则学生无法对图理解

### 5. 检查维度
| 维度 | 关注点 |
|------|--------|
| 内容准确性 | 讲稿与 PPT 核心概念一致，无科学错误 |
| 清晰度 | 口语化表达自然，易于理解，不死读PPT |
| 精炼度 | 篇幅适中、不冗长、不偏离主题 |
| 页码对应 | Pn 编号与 PPT 页面一一对应 |

### 6. 报告结构
每个 docx 文件一节，含：
- 逐页对应表（P编号 vs PPT页 vs 主题 vs 匹配情况）
- 内容评价（优点 + 问题清单）
- 问题按 🔴必须 / 🟡建议 / 🟢可选 分级
- 综合评分（内容准确性/清晰度/精炼度 + 综合分）

### 常见问题
- **P4 重复**：两个不同内容段都标为 P4，后续页码全部错位 → 必须修复编号
- **讲稿深度 > PPT 展示**：讲稿提具体技术组件但 PPT 只有概括性流程图 → 统一术语或补 PPT 标注
- **内容滞后**：讲稿引用旧年份模型（如只提 Make-A-Video 不提 Sora）→ 更新内容
- **docx 嵌入图片缺失**：read_file 提取 docx 时不提取图片，需单独用 python-docx 的 `inline_shapes` 或 `part.related_parts` 提取
